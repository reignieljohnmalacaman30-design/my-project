REIGNIEL'S IT STUDENT PORTFOLIO

HOW TO OPEN
1. Extract the ZIP file.
2. Open the reigniel-portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

FILES
- index.html: portfolio content and sections
- style.css: design and responsive layout
- script.js: mobile navigation and current year

IMPORTANT: PERSONALIZE BEFORE SUBMITTING
- Replace the sample email, GitHub, and LinkedIn links with your real details.
- Add your school name and expected graduation year.
- Check that every listed skill is one you can demonstrate.
- Replace the sample project descriptions with your actual project problem, solution, role, tools, result, and screenshots or working links.
- Add screenshots or GitHub links for at least two real projects.

The page is built with HTML, CSS, and JavaScript and is responsive on mobile screens.
